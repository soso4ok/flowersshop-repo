# Flowers Shop Frontend

React + Vite frontend for the Flowers Shop application.

## Prerequisites

- Node.js 20+
- npm

## Development

1. Install dependencies:

```bash
npm install
```

2. Create `.env` (or set env vars in shell):

```env
VITE_API_KEY=http://localhost:8080/api/v1
```

3. Start dev server:

```bash
npm run dev
```

Default dev URL: `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

## Scripts

- `npm run dev` - start Vite dev server
- `npm run build` - create production build
- `npm run preview` - serve production build locally
- `npm run lint` - run ESLint
